WHAT ARE INTERNET SERVICE

AITSCCTV บริการติดตั้งระบบอินเทอร์เน็ต-อินทราเน็ตสำหรับองค์กร

บริการออกแบบ และติดตั้งอินเทอร์เน็ต

ในโรงแรม หอพัก คอนโด สถานที่ขนาดใหญ่ เน็ตองค์กร ออกแบบระบบ Corporate Internet ติดตั้งระบบ WiFi ทั้งภายในและภายนอกอาคาร

  • วิเคราะห์และวางแผนการติดตั้งอินเทอร์เน็ต
  • บริการติดตั้ง ระบบเครือข่ายคอมพิวเตอร์ไร้สาย (Wireless)
  • ติดตั้งอินเทอร์เน็ต เพื่อลดหรือแก้ไขข้อจำกัดในการเดินสายแลนไม่สามารถทำได้สะดวก
  • ติดตั้งอินเทอร์เน็ต เพิ่มช่องทางการติดต่อสื่อสารในระบบเครือข่ายคอมพิวเตอร์

ดูแลติดตั้งอินเตอร์เน็ต ติดตั้ง WiFi ติดตั้งไวไฟบ้าน

บริการรับปรับแก้ เช็กเน็ต แก้อินเตอร์เน็ตช้า WiFi หลุดบ่อย WiFi ช้า อินเทอร์เน็ตติด ๆ ดับ ๆ

รับวางระบบไวไฟ WiFi จากทีมงานมืออาชีพ

  • บริการวางระบบไวไฟ โดยทีมงานผู้เชี่ยวชาญ มีประสบการณ์
  • ผลิตภัณฑ์สำหรับการวางระบบ WiFi จากแบรนด์ชั้นนำ
  • วิเคราะห์ และวางระบบไวไฟ WiFi โดยคำนึงถึงความปลอดภัย

บริการอุปกรณ์ เทคโนโลยี วางระบบไวไฟ WiFi

  • ระบบเทคโนโลยีสำหรับการเชื่อมต่อสัญญาณระบบ WiFi
    ได้แก่ Beam forming และ Fast roaming
  • ระบบเทคโนโลยีสำหรับรองรับอุปกรณ์ปดิจิตอล ให้สามารถเข้าถึงระบบไวไฟ
    ได้แก่ Dual-Band
  • ระบบเทคโนโลยีสำหรับรองรับความปลอดภัยในการวางระบบ Wifi
    ได้แก่ Multi SSID และ Guest , Hotspot2.0

ติดตั้งเครื่องขยายสัญญาณ WiFi
ติดตั้งระบบ Access Point

access point คือ การออกแบบการวางระบบ WiFi ขยายจุดรับบริการติดตั้งจุดWiFi ขยายสัญญาณ Hot Spot แก้สัญญาณ WiFi หาย สัญญาณ WiFi ไม่ขึ้น สัญญาณ WiFi ไม่เสถียร ด้วย Access Point ราคาพิเศษ คุณภาพสูง

บริการติดตั้ง Access point บนฝ้าภายในอาคาร

  • รับติดตั้ง Access point ในอาคาร ออฟฟิศ สำนักงาน และบ้าน
  • เน้นการติดตั้งที่สวยงาม ติดบนฝ้าหรือผนัง

บริการติดตั้ง Access point ติดตั้งในอาคาร บนโต๊ะ

  • บริการติด Access point ไว้ที่โต๊ะ ชั้น 
  • เหมาะกับกรณีที่ไม่สะดวกติด Access point ไว้บนฝ้า เผดาน หรือผนัง 

บริการติดตั้ง Access point ติดตั้งนอกอาคาร

  • บริการติดตั้ง Access point นอกอาคาร 
  • ใช้อุปกรณ์ Access point ที่มีความคงทนเป็นพิเศษต่อสภาพอากาศ อุณหภูมิ

INTERNET-INTRANET SYSTEM

อินเทอร์เน็ต (Intranet) คืออะไร แตกต่างจาก (Internet) อย่างไร

ระบบอินเทอร์เน็ต (Internet) เป็นเครือข่ายที่สำคัญอย่างมากเนื่องจากเป็นเครือข่ายที่ใช้เชื่อมต่อกับเน็ตเวิร์คให้เชื่อมโยงกันที่เชื่อมโยงทั่วโลก ช่วยให้ทั้งโลกสามารถติดต่อสื่อสารด้วยกันได้อย่างง่ายดาย ซึ่งระบบการติดตั้งและใช้งานของอินเทอร์เน็ตนั้นมีการแบ่งการใช้งานได้ดังนี้

1. อินเทอร์เน็ต (Internet)

เป็นเครือข่ายระบบคอมพิวเตอร์ที่เชื่อมโยงกันในระบบ Global Network นิยมใช้งานหลากหลายกว่า 60 ล้านคนทั่วโลก สามารถใช้งานได้ทั้งการพูดคุย-ส่งสารข้อมูลต่าง ๆ ข้อดีคือการใช้สัญญาณอินเทอร์เน็ตนั้นสามารถเข้าถึงการใช้งานได้ทุกคน การใช้งานไม่ยุ่งยาก นิยมใช้ติดตั้งในบ้าน พื้นที่อยู่อาศัย

2. อินทราเน็ต (Intranet)

Corporate internet คือ การใช้งานอินเทอร์เน็ตในองค์กร เป็นระบบเครือข่ายออนไลน์ที่เหมือนกับอินเทอร์เน็ต แต่ว่ามีการออกแบบระบบออกมาเพื่อจำกัดการใช้งานเฉพาะในองค์กร หน่วยงาน บริษัท และสถาบันขนาดใหญ่ ข้อดีของการติดตั้งอินทราเน็ตก็คือสามารถตั้งค่าให้เข้าใช้งานเป็นแบบเครือข่ายส่วนตัวเท่านั้น และการใช้งานยังมีความปลอดภัย ป้องกันการโจมตีจากแฮกเกอร์ได้มากกว่า เพราะอินทราเน็ตจะอนุญาตให้ใช้งานเฉพาะผู้ที่สิทธิ์ใช้เท่านั้น

อินทราเน็ต VS อินเทอร์เน็ตแตกต่างกันยังไง

ประเภทเครือข่าย การเข้าถึงข้อมูล ความเร็ว การจำกัดการใช้งาน ความปลอดภัย
อินทราเน็ต (Intranet) ใช้ได้เฉพาะในองค์กรและให้ใช้งานเฉพาะผู้ที่สิทธิ์ใช้ มีความเสถียรและรวดเร็วมากกว่า ใช้งานไม่สะดุด ไม่หลุดไม่หาย จำกัดการใช้งานเฉพาะผู้ที่ได้รับอนุญาต ปลอดภัยสูง ป้องกันแฮกเกอร์ได้ดี
อินเทอร์เน็ต (Internet)  สามารถใช้ข้อมูลไม่จำกัด ใครก็เข้าใช้งานได้ ในกรณีที่ใช้งานหลายคน สัญญาณมักจะช้า กระตุก  ไม่จำกัดการใช้งาน ปลอดภัยน้อยกว่า

คำถามที่พบบ่อย

ทำไม WiFi ถึงช้า
ปัญหาเรื่องอินเทอร์เน็ตช้า สามารถเกิดได้จากสาเหตุหลัก ๆ ได้ 2 แบบคือ 1. จุดส่งสัญญาณ Wi-Fi อาจจะมีน้อยเกินไป ทำให้ไม่สามารถส่งสัญญาณเพียงพอ แนะนำให้ติดกล่องรับสัญญาณเพิ่ม 2. มีคนใช้งานหลายเครื่อง แนะนำให้ลดการใช้งานลง
ทำไมสัญญาณ Wi-Fi ไม่ดี หรือขาดหายบ่อย เกิดจากอะไร
ในกรณีที่ใช้งานห่างกับจุดรับสัญญาณ แนะนำให้ลองขยับเข้ามาใช้งงานใกล้ ๆ กับ Router-WiFi ให้มากขึ้น เพราะอาจเกิดจากตำแหน่งที่ใช้งานอาจจะอยู่ห่างจากจุดปล่อยสัญญาณมากเกินไป หรือไม่ก็ลองย้าย Router-WiFi ออกจากมุมอับ ในกรณีที่ลองย้ายแล้วไม่หาย อาจเกิดจากสัญญาณเครือข่ายไม่เพียงพอ
ใช้ WiFi หลายเครื่องเน็ตช้าไหม
ช้าแน่นอน เพราะเครือข่ายรับภาระหนักเกินไป ทำให้แถบคลื่นความถี่ในการส่งข้อมูลไม่เพียงพอ แนะนำให้ลดจำนวนการใช้งานให้น้อยเครื่องลง เช่นจากเดิมใช้พร้อมกัน 4 เครื่อง แนะนำให้เหลือแค่ 1-2 เครื่อง
ปัญหาสัญญาณ WiFi ขัดข้องเกิดจากอะไร
ปัญหาสัญญาณ WiFi ขัดข้องอาจเกิดจากหลายสาเหตุ ทั้งพื้นที่กว้างเกินไปทำให้สัญญาณส่งไปไม่ถึง Router ไม่ดี หรืออาจจะเป็นที่เสาสัญญาณขัดข้องก็ได้
ระยะห่างของเครื่อง Router-WiFi ควรห่างเท่าไร
แนะนำให้อยู่ห่างไม่เกิน 5-7 เมตรจากจุดใช้งาน
ทำไมเน็ตบ้านใช้ไม่ได้
ส่วนใหญ่เมื่อเน็ตบ้านใช้งานไม่ได้มักจะเกิดจากปัญหา Router-WiFi แนะนำให้ตรวจสอบ Router-WiFi ว่ามีการเชื่อมต่อถูกต้องหรือไม่ ปลั๊กหลวม หรือหลุดหรือไม่ สายชำรุดไหม หากตรวจแล้วปกติให้ลองเปิด-ปิด Router-WiFi ว่ามีสัญญาณไฟเข้าหรือไหม ถ้าสัญญาณอินเทอร์เน็ตปกติจะมีไฟติดอยู่ แต่ถ้าไม่ปกติสัญญาณจะไม่ติดหรือติดแบบกะพริบ
เน็ตบ้านปิดได้ไหม
สามารถปิดได้เมื่อไม่มีการใช้งาน การปิดเครื่อง Router-WiFi จะช่วยยืดอายุการใช้งานของเครื่องให้นานขึ้นจากการระบายความร้อนของตัวเครื่อง
ทํายังไงให้เน็ตบ้านเร็วขึ้น
วิธีการทำให้เน็ตบ้านใช้งานได้ดีขึ้น ดังนี้แนะนำให้เปิด-ปิด Router-WiFi เมื่อไม่ได้ใช้งานย้าย Router-WiFi ออกจากมุมอับ หรือขยับให้ใกล้กับจุดใช้งานมากขึ้นลดจำนวนเครื่องการใช้งานติดตั้งเครื่องขยายสัญญาณ WiFi
ทำไมใช้อยู่แล้วเน็ตกระตุก
อาจจะเกิดจากใช้งานในพื้นที่การใช้งานหนาแน่นหรือพื้นที่ที่มีผู้ใช้งานเยอะ
สัญญาณ WiFi ผ่านกระจกได้ไหม
สัญญาณ WiFi จะใช้งานหรือส่งสัญญาณได้ยากขึ้นเมื่อต้องส่งผ่านผนังกระจก หรือมีวัสดุเหล็ก หรือสเตนเลสวางอยู่ใกล้ ๆ เพราะวัสดุเหล่านี้มักจะสะท้อนสัญญาณ WiFi ให้ลดประสิทธิภาพลง
Corporate Internet ราคาเท่าไร
ค่าบริการติดเน็ตองค์กรราคาจะขึ้นกับขนาดของจำนวนผู้ใช้งาน อุปกรณ์ที่เชื่อมต่อ และความเร็วของอินเทอร์เน็ต ทางที่ดีควรสอบถามกับผู้ให้บริการติดตั้งจะดีที่สุด
